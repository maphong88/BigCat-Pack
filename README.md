# BigCat-Pack
BigCat CFW pack for Nintendo Switch CFW

## Releases
Each release is built for a specific firmware.
Check the release notes for the supported firmware, Atmosphère and hekate versions.
Download: see the **Releases** section on the right.

## Features
- Anti-ban: dns.mitm, blanked serial (prodinfo), telemetry off
- BigCat-AMS (Atmosphère build)
- Ready-to-use homebrew apps

## Install
Extract the zip, then copy everything inside the pack folder to the root of your SD card.

## Important
- Always back up your NAND first.
- Use CFW on emuMMC only.
- Do not go online on sysMMC while the serial is blanked.
- Use at your own risk.
